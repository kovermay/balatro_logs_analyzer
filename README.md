# Balatro Multiplayer — Log Viewer

Веб-приложение для просмотра логов мультиплеера Balatro (мод *Multiplayer / TheOrder*,
который пишет логи через `lovely`). Парсит все логи из папки модов и показывает
каждую сыгранную партию в удобном виде: детали игры, колоды обоих игроков, финальные
джокеры, ваучеры, траты в магазине, PVP-блайнды с послайновым счётом и полный таймлайн
событий. Есть избранное, поиск/фильтры и страница общей статистики.

## Возможности

- **Первый запуск** — приложение спросит папку с логами (с автоопределением и проверкой).
- **Список всех игр** с поиском (игрок/колода/сид/лобби), фильтрами и сортировкой.
- **Избранное** — звёздочка на карточке или в детальном виде.
- **Детальный просмотр** партии — все панели как у разработчиков мода.
- **Статистика** — большая сводка по всем играм (см. ниже).
- **Настройки** — смена папки с логами, выбор темы (4 шт.), акцентный цвет,
  и кастомизация цветов улучшений карт и печатей с живым предпросмотром.

## Статистика (вкладка Stats)

Винрейт, серии побед/поражений, общее и среднее время игры; винрейт по роли
(Host/Guest), ставке, колоде и ruleset; таблица личных встреч с соперниками;
экономика (всего рероллов и их стоимость, траты в магазине, сыграно рук, продано
джокеров); PVP (сыграно блайндов, винрейт, самая большая рука и блайнд за всё время);
топ джокеров, ваучеров и колод; распределение изданий финальных джокеров; график
активности по месяцам.

**Рекорды и хайлайты** — клик по карточке открывает ту самую игру: наибольший перевес
по экономике в долларах и в процентах, лучший «камбэк» (победа при меньших тратах),
самая дорогая закупка за игру и за один магазин, больше всего рероллов, самый крупный
разгром в PVP, больше всего сыгранных рук, продано джокеров, самая длинная игра.

## Интерактивный график экономики (в каждой игре)

Дивержентный график трат по магазинам: сверху — твои траты, снизу — соперника,
по центру — линия паритета. PVP-блайнды отмечены золотыми полосами с ⚔, снизу —
номера магазинов и анте. При наведении показывает точные суммы за каждый магазин
и разницу. Длинные игры прокручиваются по горизонтали.

## Что показывается по каждой игре

- **Game Details** — твоя роль (Host/Guest), победитель, колода, сид, код лобби,
  ставка, ruleset, режим, количество и стоимость рероллов обоих игроков, и все
  настройки лобби (Death on Round Loss, Gold on Life Loss, Different Decks/Seeds и т.д.).
- **Deck Snapshots** — колоды обоих игроков: сколько карт, модифицированных, с
  улучшениями, изданиями и печатями. Кнопка **View deck** показывает все карты по мастям
  с цветовой раскраской улучшений, печатями и свечением изданий.
- **Final Jokers** — финальные джокеры обоих игроков с изданиями (foil / holo /
  polychrome / negative) и пометкой MP для джокеров мода.
- **Vouchers** — купленные ваучеры обоих игроков.
- **Shop Spending** — траты по каждому магазину для обоих игроков + итоги.
- **PVP Blinds** — счёт по каждому PVP-блайнду (победа/поражение), а в раскрывающемся
  блоке — счёт по каждой руке. Большие числа считаются через BigInt (точно).
- **Events** — хронология событий (твои / соперника / ключевые моменты) с фильтром.

## Запуск

> ⚠️ Это **не** обычная HTML-страница — её нельзя открыть двойным кликом по
> `index.html`. Нужен запущенный локальный сервер (он читает логи и отдаёт данные).
> Если открыть файл напрямую, будет ошибка «Could not reach the server».

Нужен только **Node.js 18+** (зависимостей нет, `npm install` не требуется).

**Самый простой способ (Windows):** дважды кликни по **`start.bat`**.
Откроется чёрное окно, само запустится приложение и откроется браузер на
http://localhost:4173. Это окно нужно держать открытым, пока пользуешься
приложением (закрыть окно = остановить сервер).

**Через терминал:**

```bash
cd logs_balatro_analyze
npm start
```

Затем открой в браузере: **http://localhost:4173**

По умолчанию логи читаются из стандартной папки:

```
%APPDATA%\Balatro\Mods\lovely\log
```

### Если папка с логами в другом месте

Проще всего — указать её при первом запуске или потом во вкладке **Settings →
Logs Folder**. Либо вручную создай файл `config.json` рядом с `server.js`:

```json
{
  "logDir": "D:\\путь\\к\\папке\\log",
  "port": 4173
}
```

…либо запусти с переменной окружения:

```powershell
$env:BALATRO_LOG_DIR = "D:\путь\к\папке\log"; npm start
```

## Как это работает

- Логи парсятся **на лету** при запросе и кешируются по времени изменения файла —
  новые сыгранные партии появляются после обновления страницы, без перезапуска.
- Поддерживаются **оба формата** логов: старый (мод ≤ 0.2.x, `action:key:val`) и новый
  (≥ 0.3.x, JSON-сообщения).
- Один лог-файл обычно содержит несколько партий — каждая показывается отдельной карточкой.
- Избранное хранится в `data/favorites.json`.

## Структура проекта

```
server.js            — HTTP-сервер (без зависимостей): API + раздача фронтенда
lib/parser.js        — парсер лога → массив игр
lib/gameData.js      — словари: имена джокеров/ваучеров/колод, ставки, масти и т.д.
lib/jokers.json      — карта «ключ джокера → имя»
public/              — фронтенд (index.html, styles.css, app.js)
data/favorites.json  — избранное (создаётся автоматически)
config.json          — необязательный конфиг (путь к логам, порт)
```

## Картинки джокеров (опционально)

Сейчас джокеры и карты рисуются красивыми CSS-плитками (без внешних картинок —
работает офлайн). Поддержка настоящих спрайтов **уже встроена**: просто положи
PNG-файлы в `public/assets/jokers/<ключ>.png` (например `j_photograph.png`,
`j_mp_bloodstone.png`) — приложение само подхватит их и заменит плитку картинкой,
а для джокеров без файла останется плитка. Ключи джокеров видны в подсказке при
наведении на джокер.
